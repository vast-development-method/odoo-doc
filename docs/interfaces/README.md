# Interfaces

The contracts through which people and other systems use the platform.

| Document | Content |
|---|---|
| `desktop-workflows.md` | How the desktop client composes views, actions and menus into working screens: navigation, breadcrumbs, form and list editing, batch actions, search and filters, favorites, kanban, calendar, pivot and graph, spreadsheets, the command palette, keyboard shortcuts and notifications |
| `endpoint-catalog.md` | Every route exposed over Hypertext Transfer Protocol: path, method, authentication, request type, purpose, inputs, outputs, errors |
| `external-integrations.md` | Every integration with an outside service: payment providers, shipping carriers, document exchange network, calendar and mail services, in-app purchase services, geolocation, address autocompletion, cloud storage, text message gateways |
| `remote-transport-contracts.md` | The remote procedure call transport: envelope, sessions, generic entity operations (create, read, write, unlink, search, search_read, read_group, name_search, fields_get, default_get, onchange, web_search_read, web_read, web_save), named operations, errors, batching, contexts |
| `report-and-export-documents.md` | Printable documents and exports: report actions, templates, paper formats, document layouts, spreadsheet and comma-separated exports, electronic document formats |
| `service-layer.md` | The named business operations exposed on entities, grouped by domain, with inputs, outputs, preconditions and side effects |
