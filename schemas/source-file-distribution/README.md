# Source file distribution

An inventory of this repository itself, so that a reader or a tool can see where the specification's mass sits.

| Catalogue | Content | Records |
|---|---|---|
| [`files.json`](files.json) | Every file with its path, purpose, domain, size and line count | 3,541 |
| [`summary.json`](summary.json) | Counts and sizes grouped by purpose and by domain | 21 |

Both are regenerated whenever the repository changes, so the counts in [coverage and evidence](../../docs/reimplementation/coverage-and-evidence.md) are measured rather than asserted.
